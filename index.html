Ejecutar FitControl (JNLP)

Instrucciones para ejecutar

  1. Tener Java 8 instalado (incluye Java Web Start). Si no lo tiene, descargarlo de java.com.
  2. Agregar este sitio a la lista de excepciones de Java (solo la primera vez):
    Buscar en Windows "Configurar Java" → pestana Seguridad → Editar lista de sitios → Agregar → escribir:
    https://elizabeth120109.github.io
    → Aceptar → Aceptar.
  3. Hacer clic en el boton verde "Ejecutar FitControl (JNLP)". Se descarga fitcontrol.jnlp: abrirlo con doble clic.
    O desde la consola (CMD): 
    javaws https://elizabeth120109.github.io/fitcontrol/fitcontrol.jnlp
  4. En el aviso de seguridad, marcar "Acepto el riesgo y deseo ejecutar esta aplicacion" → Ejecutar.
  5. Se abre FitControl con datos de ejemplo ya cargados (socios, planes, membresias y suspensiones).

Si algo falla

"Aplicacion bloqueada por la seguridad de Java"Falta el paso 2 (agregar el sitio a la lista de excepciones).
Se abre una version antigua o da errorLimpiar la cache de Java en CMD: javaws -uninstall y volver a intentar.
"javaws" no se reconoceInstalar Java 8 desde java.com (las versiones 11+ ya no incluyen Java Web Start).

Detalles tecnicos

  • Compilado para Java 8 (compatible con Java 8 o superior).
  • JAR firmado con certificado propio (por eso se requiere la excepcion de sitio).
  • Los datos se guardan en archivos .txt; si no existen, se crean con datos de ejemplo.
  • Modulos: Mantenimiento (Socios, Planes), Registro (Membresias, Suspensiones), Consultas y Reportes.
