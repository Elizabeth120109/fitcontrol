Ejecutar FitControl (JNLP)
  1. Requiere Java 8 (con Java Web Start).
  2. Panel de Control de Java > Seguridad > Editar lista de sitios > agregar la direccion de esta pagina.
  3. Descargar y abrir fitcontrol.jnlp, aceptar el aviso de seguridad.
